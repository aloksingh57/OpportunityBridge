## Scope and release decision

The repository currently provides a functioning local demo and an optional Supabase authentication/profile pilot, not a production release. The production build must not silently let visitors sign in as fictional accounts or write to a process-local JSON file: demo routes are disabled by default when `NODE_ENV=production`. Only configured Supabase account routes are allowed; `/api/health/ready` continues to report `productionReady: false` and all remaining platform blockers.

Supabase variable names are present in the local `.env.local`, but their values are empty; no usable Supabase authentication credentials, `DATABASE_URL`, complete workflow data adapter, or object-storage credentials were found. The profile migration was added but not applied. No hosted deployment or production migration was run.
